📘 Cài đặt Sổ Tự Học

Làm lần lượt từng bước. Mỗi khoá bí mật chỉ dùng trong lúc cài và không được lưu lại.

    1. Kiểm tra cài đặt trên Vercel

    Trang này đọc 3 biến môi trường bạn đã điền lúc bấm Deploy.

      Cách thêm biến còn thiếu

      1. Mở project trên Vercel → Settings → Environment Variables.
      2. SUPABASE_URL và SUPABASE_PUBLISHABLE_KEY: trên Supabase, mở project trống của bạn → bấm nút Connect ở trên cùng (hoặc Project Settings → API Keys). Chép Project URL (dạng https://xxxx.supabase.co) và Publishable key (bắt đầu bằng sb_publishable_).
      3. SETUP_PASSWORD: tự đặt một mật khẩu (ít nhất 8 ký tự) để chỉ bạn mở được trang cài đặt này.
      4. Lưu xong, vào tab Deployments → bấm ⋯ ở bản mới nhất → Redeploy, rồi tải lại trang này.

      2. Mật khẩu cài đặt

      Nhập SETUP_PASSWORD bạn đã đặt trên Vercel.

      3. Kết nối Supabase

      Bộ cài cần một Access Token của tài khoản Supabase để tạo cơ sở dữ liệu và các hàm máy chủ trong project của bạn.

      1. Mở trang Supabase → Access Tokens (đăng nhập bằng tài khoản sở hữu project).
      2. Bấm Generate new token, đặt tên ví dụ so-tu-hoc-cai-dat. Nếu được chọn thời hạn, chọn ngắn nhất (1 ngày).
      3. Bấm Generate token và chép token vừa hiện (bắt đầu bằng sbp_). Token chỉ hiện một lần.
      4. Dán vào ô dưới rồi bấm Kiểm tra.

      Project sẽ cài: — (lấy từ SUPABASE_URL).

      4. AI duyệt đăng ký tuỳ chọn

      Có khoá Groq (miễn phí) thì AI tự duyệt các đăng ký tự học rõ ràng. Bỏ qua thì giáo viên duyệt tay, app vẫn chạy đầy đủ.

      1. Mở Groq Console → API Keys (đăng nhập bằng Google được).
      2. Bấm Create API Key, đặt tên ví dụ so-tu-hoc, bấm Submit.
      3. Chép khoá vừa hiện (bắt đầu bằng gsk_), dán vào ô dưới rồi bấm Kiểm tra.

      5. Ảnh trong báo bài tuỳ chọn

      Ảnh đính kèm báo bài được lưu ở Cloudflare R2 (miễn phí tới 10 GB, Cloudflare yêu cầu khai báo thẻ thanh toán khi bật R2). Bỏ qua thì báo bài vẫn dùng được bằng chữ.

      1. Mở Cloudflare → R2 Object Storage và bật R2 nếu chưa bật.
      2. Bấm Create bucket, đặt tên ví dụ so-tu-hoc-anh, bấm Create. Chép tên bucket vào ô Bucket.
      3. Ở trang R2, chép Account ID (32 ký tự) vào ô Account ID.
      4. Bấm Manage API tokens → Create API token. Chọn quyền Object Read & Write, chỉ áp dụng cho bucket vừa tạo, bấm Create.
      5. Chép Access Key ID và Secret Access Key vào hai ô cuối (Secret chỉ hiện một lần), rồi bấm Kiểm tra.

      6. Tài khoản quản trị

      Đây là tài khoản đầu tiên của trường. Đăng nhập bằng nó để tạo năm học, lớp, giáo viên và học sinh.

      7. Cài đặt

          🎉 Cài đặt xong!

          Đăng nhập Sổ Tự Học bằng tên đăng nhập và mật khẩu bạn vừa đặt.

          Mở Sổ Tự Học

          Nên làm ngay

          1. Xoá Access Token vừa tạo ở Supabase → Access Tokens (bấm ⋯ → Delete). Bộ cài không cần nó nữa.
          2. Trang cài đặt đã tự khoá. Bạn có thể xoá biến SETUP_PASSWORD trên Vercel.
